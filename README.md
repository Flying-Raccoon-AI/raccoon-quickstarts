# React Tail SDK 

## Run Locally

Clone the repository -
```shell
git clone -b tail-react https://github.com/Flying-Raccoon-AI/raccoon-quickstarts raccoon-tail-react
```

Setting up environment variables
```shell
cd raccoon-tail-react
```
```shell
cp .env.example .env.local
```

Add `VITE_RACCOON_SECRET_KEY` and `RACCOON_USER_PASSCODE` variables.

Start the applicaton - 

```shell
npm install
npm run dev
```
